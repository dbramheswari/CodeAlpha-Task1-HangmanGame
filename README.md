# 🎮 Hangman Game - CodeAlpha Internship Task 1

This is my Task 1 for CodeAlpha Python Internship.

### 📝 About Project
A classic Hangman game built using Python. The computer selects a random word and the player has to guess it letter by letter with limited attempts.

### 🚀 Features
- Random word selection
- 6 lives / attempts
- Visual representation of guessed letters
- Input validation

### ▶️ How to Run
1. Download or clone this repository
2. Run the file: `python hangman.py`
3. Start guessing letters!

### 🛠️ Tech Used
- Python 3
- Random module
